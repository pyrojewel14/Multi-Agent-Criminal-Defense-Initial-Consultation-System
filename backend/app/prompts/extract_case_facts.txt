从咨询者描述中提取刑事案件关键事实要素。

请提取以下字段：
- incident_time: 事件发生时间
- incident_location: 事件发生地点（已脱敏）
- parties: 当事人列表（包含 role, name, relationship）
- behavior_sequence: 行为时间序列（包含 time, actor, action, method, target）
- consequence: 后果描述
- evidence_mentioned: 提到的证据线索
- arrest_status: 当前羁押状态
- surrender: 是否自首
- victim_forgiveness: 被害人是否谅解
- prior_record: 是否有前科劣迹

必须返回全部字段。字符串或布尔字段不明确时设为 null；列表字段不明确时使用空数组，不得省略字段：

```json
{
  "incident_time": null,
  "incident_location": null,
  "parties": [],
  "behavior_sequence": [],
  "consequence": null,
  "evidence_mentioned": [],
  "arrest_status": null,
  "surrender": null,
  "victim_forgiveness": null,
  "prior_record": null
}
```
